# Refactor Plan for `trainscripts/imagesliders`

**Date:** 2025-07-05 17:00:00

This plan outlines the steps to address critical tensor shape errors in the data loading pipeline and simplify configuration management by removing Pydantic.

## Refactor Points:

### 1. Refactor `batch_config_util.py` to remove Pydantic and streamline config loading into a single `AttrDict`.
*   **Details:**
    *   Remove all `pydantic.BaseModel` class definitions (`PretrainedModelConfig`, `NetworkConfig`, `TrainConfig`, `SaveConfig`, `LoggingConfig`, `OtherConfig`, `RootConfig`).
    *   Remove `typing.Literal` and `typing.Optional` imports if they are only used by Pydantic models.
    *   Modify the `config_io` function to directly load YAML files using `load_config_from_yaml` and merge them into a single `AttrDict` structure.
    *   Remove the `load_config_from_yaml_and_merge` function as it will no longer be necessary.
    *   Adjust `envsetup` to access config parameters directly from the `AttrDict` instead of Pydantic model attributes.

### 2. Modify `collate_fn` in `batch_config_util.py` to correctly use the concatenated pooled embeddings.
*   **Details:**
    *   Ensure that the `pooled_embeds` returned by `batch_train_util.create_batched_prompt_embeddings` are correctly assigned and passed through the `collate_fn` to the training loop. The current issue is that `create_batched_prompt_embeddings` is returning `positive_pooled_embeds` instead of the full concatenated `pooled_embeds_for_noise_pred`.

### 3. Adjust `create_batched_prompt_embeddings` in `batch_train_util.py` to return the full concatenated pooled embeddings and remove the deprecated `num_images_per_prompt` argument.
*   **Details:**
    *   In `batch_train_util.py`, modify the `create_batched_prompt_embeddings` function's return statement to `return text_embeddings_for_noise_pred, pooled_embeds_for_noise_pred`.
    *   Remove the `num_images_per_prompt` argument from `create_batched_prompt_embeddings`, `encode_prompts_xl`, and `text_encode_xl` as it is no longer needed and was causing incorrect tensor reshaping. Also remove the related `repeat` and `view` operations.

### 4. Integrate tensor unswizzling from `batch_slider_algo.py` as needed.
*   **Details:**
    *   After ensuring the correct three text conditioning embeddings are present and correctly shaped, read `F:/dox/ai/gemmy/sliders/trainscripts/imagesliders/batch_slider_algo.py` to understand the unswizzling logic.
    *   Apply the unswizzling logic within `batched_training_loop.py` or `batch_train_util.py` where the `pooled_embeds` are prepared for the UNet, specifically before or within `batched_predict_noise_xl_modular`. This will ensure the tensors are in the expected format for the SDXL algorithm.
