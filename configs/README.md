# Configuration Files

This directory contains JSON configuration files used by various scripts in the project.

## `diff_debugger_config.json`

This file configures the `diff_debugger.py` script, specifying paths for tensor logs and model loading.

## `refactored_training_loop_config.json`

This file configures the `refactored_training_loop.py` script, specifying paths for model loading and other training parameters.
