# Tensor Logs for Diff Debugger Suite

This directory contains the output tensors generated by `refactored_training_loop.py` and analyzed by `diff_debugger.py`.

## `diff_debugger_tensors.pt`
This file is a PyTorch state dictionary containing various tensors used for debugging and comparing the original, refactored, and super-functional training steps. It includes:
- Absolute differences between losses (`diff_high_orig_refactored`, `diff_low_orig_refactored`, `diff_high_orig_super`, `diff_low_orig_super`).
- Per-element squared error losses (`loss_high_orig_per_element`, `loss_low_orig_per_element`, `loss_high_refactored_per_element`, `loss_low_refactored_per_element`, `loss_high_super_per_element`, `loss_low_super_per_element`).
- Intermediate tensors (denoised latents, noise, target latents) from each training step for detailed analysis.

## Subtractive Difference Plots
PNG images in this directory visualize the per-element subtractive differences between the original, refactored, and super-functional training steps. These plots help in visually identifying patterns and magnitudes of discrepancies.
